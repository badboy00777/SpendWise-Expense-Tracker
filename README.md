# SpendWise - Expense Tracker

A simple, responsive expense tracker built with plain HTML, CSS and JavaScript. No frameworks, no build tools.

**Live demo:** https://badboy00777.github.io/SpendWise-Expense-Tracker/

## Features
- Add, edit and delete expenses (full CRUD)
- Form validation with clear error messages
- Data saved in the browser with localStorage
- Summary cards: total spent, transactions, top category, this month
- Search, category filter and sorting
- Fully responsive layout

## Tech
HTML5, CSS3 (Grid and Flexbox), vanilla JavaScript (ES6)

## Run locally
Download or clone the repo and open `index.html` in a browser.
